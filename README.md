# 잿빛 균열 — 온라인 서버

게임 페이지와 서버가 한 프로그램에 들어 있어요. 서버를 켜고 주소로 들어가면 온라인 기능이 켜져요.

- **계정 · 클라우드 저장**: 폰과 PC에서 같은 캐릭터로 이어서 해요.
- **랭킹**: 던전별 클리어 타임(혼자 깬 기록), 무한의 탑 층수, 레벨 순위가 있어요.
- **경매장**: 장비를 올리고 사요. 판매 대금은 수수료 5%를 떼고 우편함으로 와요. 48시간 안에 안 팔리면 물건이 돌아와요.
- **실시간 멀티**: 마을에서 다른 유저가 보이고, 채팅과 말풍선이 떠요.
  - 최대 4인 파티를 맺을 수 있어요.
  - 파티장이 던전(일반·레이드)을 고르면 마을에 있는 파티원이 함께 입장해요.

## 1. 내 PC에서 켜 보기 (가장 쉬움)

1. [Node.js](https://nodejs.org) **LTS 버전**을 설치해요. 22.13 이상이 필요해요.
2. 이 폴더를 열고 `서버시작.bat`을 더블클릭해요. 처음 한 번은 설치 때문에 조금 걸려요.
   - Mac이나 리눅스에서는 터미널에서 `npm install` 다음에 `npm start`를 실행해요.
3. 창에 뜬 주소로 접속해요.
   - PC 브라우저에서는 `http://localhost:3000`
   - **같은 와이파이의 폰**에서는 창에 뜬 `http://192.168.x.x:3000` 주소를 입력해요.
     - 윈도우 방화벽 허용 창이 뜨면 "허용"을 눌러 주세요.
4. 타이틀에서 **온라인 로그인** → 회원가입을 해요. 지금 브라우저의 캐릭터가 그대로 서버에 올라가요.

PC를 끄면 서버도 꺼져요. 데이터는 `data/game.db` 파일에 남아요.

## 2. 인터넷에 올리기 — 게임은 넷리파이, 서버는 Render, 저장은 Neon

넷리파이는 페이지만 올려 두는 곳이라, 서버는 Render에 따로 띄우고 게임이 그 주소로 접속하게 해요.

Render 무료 서버는 쉬었다 깨어날 때마다 서버 안의 파일이 지워져요. 그래서 계정과 저장 데이터는 무료 PostgreSQL 데이터베이스인 **Neon**에 보관해요.

```
[넷리파이] 게임 화면  ──접속──▶  [Render] 게임 서버  ──저장──▶  [Neon] 데이터베이스
```

### ① Neon — 데이터베이스 만들기
1. https://neon.tech 에 가입하고 **Create project**를 눌러요. 지역은 가까운 곳(예: Singapore)을 고르면 돼요.
2. 대시보드의 **Connect** 버튼을 눌러 `postgresql://…` 로 시작하는 주소(Connection string)를 복사해 둬요.

### ② GitHub — 서버 코드 올리기
1. GitHub에서 새 저장소(New repository)를 만들어요. Private으로 만들어도 돼요.
2. **Add file → Upload files**를 누르고, 이 폴더 안의 파일을 전부 끌어다 놓고 Commit해요.
   - `node_modules`와 `data` 폴더는 빼 주세요.

### ③ Render — 서버 띄우기
1. https://render.com 에 GitHub 계정으로 가입해요.
2. **New → Web Service**를 누르고 ②에서 만든 저장소를 골라요.
   - Runtime: `Node` · Build Command: `npm install` · Start Command: `npm start` · Instance: `Free`
3. **Environment Variables**에 `DATABASE_URL`을 추가하고, 값에 ①에서 복사한 Neon 주소를 붙여 넣어요.
4. **Deploy**를 누르고 몇 분 기다려요. 상단에 `https://이름.onrender.com` 주소가 생겨요.
5. 브라우저에서 `https://이름.onrender.com/api/ping` 을 열어 `"ok":true` 가 보이면 성공이에요.
   - 로그에 `[저장소: PostgreSQL]` 이 찍혀 있어야 Neon에 저장되고 있는 거예요.

(`render.yaml`이 들어 있어서 **New → Blueprint**로 만들어도 같은 설정이 돼요.)

### ④ 넷리파이 — 게임 올리기
1. 함께 드린 **ashen-rift-netlify** 폴더의 `config.js`를 메모장으로 열어요.
2. 주소를 적고 저장해요: `window.GAME_SERVER = 'https://이름.onrender.com';` (끝에 `/` 없이)
3. https://app.netlify.com/drop 에 폴더째로 끌어다 놓아요.
   - 기존 사이트를 쓰려면 사이트의 **Deploys** 탭에 끌어다 놓으면 돼요.
4. 넷리파이 주소로 들어가면 타이틀에 **온라인 로그인** 버튼이 떠요.

### ⑤ (선택) 보안 한 단계 더
Render의 Environment에 `ALLOWED_ORIGINS=https://내사이트.netlify.app` 를 추가하면 내 넷리파이 사이트에서만 서버에 접속할 수 있어요.

### 무료로 쓸 때 알아 둘 점
- Render 무료 서버는 15분 동안 아무도 접속하지 않으면 잠들어요. 다음 사람이 들어올 때 깨어나는 데 1분쯤 걸려요.
  - 그동안 타이틀에 "온라인 서버를 깨우는 중…"이 떠요.
  - 데이터는 Neon에 있어서 잠들어도 지워지지 않아요.
- Render 무료는 한 달에 750시간까지예요. 서버 하나를 계속 켜 두기에는 충분해요.
- 무료 요금제 조건은 바뀔 수 있으니 각 사이트에서 한 번 확인해 주세요.

### 다른 방법
- Railway, Fly.io, 내 서버(VPS)처럼 디스크를 붙일 수 있는 곳이면 Neon 없이 `DB_PATH`를 볼륨 경로(예: `/data/game.db`)로 지정해 SQLite로 써도 돼요.
- `Dockerfile`도 들어 있어요.

## 설정 값 (환경 변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 (호스팅이 자동으로 정해 주면 그대로 둬요) |
| `DATABASE_URL` | (없음) | PostgreSQL 주소 (Neon 등). 있으면 이걸 쓰고, 없으면 SQLite 파일을 써요 |
| `DB_PATH` | `./data/game.db` | SQLite 파일 위치 (DATABASE_URL이 없을 때만) |
| `ALLOWED_ORIGINS` | (모두 허용) | 접속을 허용할 게임 주소, 쉼표로 여러 개 |

## 알아 둘 점

- **보안 수준**: 게임 계산이 각자의 브라우저에서 이뤄지는 구조예요. 마음먹고 브라우저를 조작하면 골드나 기록을 속일 수 있어요.
  - 비밀번호는 암호화(scrypt)해서 저장해요.
  - 요청 횟수 제한, 기록 값 범위 검사, 같은 아이템 중복 등록 차단 정도는 들어 있어요.
  - 지인끼리 즐기는 용도로는 충분하지만, 공개 서비스로 키우려면 서버 쪽 검증을 더 늘려야 해요.
- **협동 던전**: 몬스터는 파티장 화면이 계산하고, 파티원은 그 화면을 받아 보며 공격을 보내요.
  - 파티장의 인터넷이 느리면 파티원 화면이 살짝 끊겨 보일 수 있어요.
  - 파티원의 시간 정지·잡기 같은 특수 효과는 일부만 반영돼요.
  - 협동 중에 쓰러지면 5초 뒤 부활해요. 보상(골드·경험치·장비)은 각자 따로 받아요.
- **배경음악**: `public/`의 mp3 두 개는 직접 넣어 주신 곡이에요. 공개 서버에 올릴 때는 저작권을 확인해 주세요.
- 오프라인 버전(아티팩트 링크)은 그대로 혼자 할 수 있어요. 온라인 버튼은 서버에 연결됐을 때만 나타나요.
